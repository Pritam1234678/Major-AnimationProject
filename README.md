Project Title: Obys.Agency Website Clone

Description:

This project is a high-fidelity clone of the Obys.Agency website(Original Site-> https://obys.agency/), developed as part of a creative front-end development initiative. The clone replicates the original site's sophisticated animations and interactive user experience using modern web technologies.

Tech Stack:

Three.js – for 3D graphics and immersive visual effects

GSAP (GreenSock Animation Platform) – for smooth, timeline-based animations

Locomotive Scroll – to achieve smooth scrolling with parallax effects

HTML, CSS, JavaScript – as the foundational front-end technologies

Features:

Pixel-perfect replication of the Obys.Agency site layout and interaction patterns

Advanced scroll-based animations and transitions

Seamless integration of 3D elements using Three.js

Responsive and smooth user experience across devices

High-performance rendering with optimized animation pipelines

Purpose:

This project demonstrates expertise in modern front-end animation libraries and frameworks. It showcases the ability to translate complex motion design and UI/UX patterns into performant, interactive code.
